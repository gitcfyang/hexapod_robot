校准
三件事都在这页：舵机机械中心 · 电压标定（万用表实测 → 分压比）· IMU 校准（姿态水平 / 加速度六面）。舵机调试与 IMU 复位期间主循环会停摆， 两者都要先把机器人架空或平放好、并确认舵机供电状态符合预期。 校准舵机就是给每一路定机械中心：点格子选中 → 用滑条/微调把它转到中立位 → 按「设为中心」记下这一路的偏移（写入后立即参与 IK，不必重启） → 18 路都调完再按「!SAVE 保存校准」落到 flash。没调过的舵机保留出厂默认偏移。

滑条与微调按钮松手即下发 !P<id> <角度>（直接把这一路舵机转过去， 绕过 IK）；「设为中心」下发 !HO <id> <角度>， 把当前角度记成这一路的 horn_offset —— 写完 立即生效，之后走路的姿态就按新中心算。角度单位 0.1°， 0 = 舵机中位 1500µs，±900 = ±90° 极限位置（板子上的摇臂多半到不了 ±90°， 转到顶住就别再往上加，会憋舵机）。机器人须处于锁定状态，解锁时会拒绝。 偏移只在本页与固件里各留一份，掉电前记得按「!SAVE 保存校准」。

单点标定：分压比 = 万用表实测的电池电压 ÷ 此刻的 ADC 引脚电压 （引脚电压与分压比无关，是这条式子的基准量；固件读数 = 引脚电压 × 分压比）。 填值 → 按「按实测标定」，新比值立即生效（上面的「当前分压比」跟着变， 也就是「电源」页的 batt_ratio_milli）；再按「保存到 Flash」掉电保持 （须已上锁）。未接电池时读数无效，按钮会被禁用。 误差来源是 330k‖47k 的源阻抗、电阻容差与 3.3V 轨偏差 —— 换板或换稳压方案后要重标一次。

IMU 校准

在线—
Roll / Pitch—
校准等级 sys/gyr/acc/mag—
BNO055 的标定由芯片自己维护（NDOF 融合连续自校准），固件做的是显示与 「清空重来」：
姿态（水平）：机器人平放几秒，sys/gyr 先到 3 —— 此时显示的 Roll/Pitch 就是这台机器的水平零点，平放时读数应 ≈0°，明显不为 0 就该重置 重标（或检查机身/传感器是不是装歪了）。
加速度（六面）：需要六个面各朝上静止停一会儿，acc 才会从 0 爬到 3； 磁力计（mag）得在原地缓慢转几圈。
重置 = 整芯片复位 + 重新初始化（约 0.7 秒，清空全部校准值）， 须处于锁定状态，解锁时会拒绝执行；复位后姿态短暂无效、 等级从 0 重新爬升，都属正常。等级每秒刷新一次。
